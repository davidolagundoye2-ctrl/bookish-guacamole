# Hudson House Restaurant Website

A modern, responsive website for Hudson House, a premier restaurant located in Dallas, Texas, specializing in fresh seafood, oysters, burgers, and craft cocktails.

## Features

- **Responsive Design**: Mobile-first approach that works seamlessly on all devices
- **SEO Optimized**: Meta tags and semantic HTML for search engine visibility
- **Accessibility**: Proper heading hierarchy and semantic markup
- **Performance**: Optimized assets and minimal dependencies
- **Professional Styling**: Clean, modern design with premium color scheme
- **Interactive Elements**: Hover effects and smooth transitions
- **Location Integration**: Embedded Google Maps for easy navigation
- **Contact Integration**: Direct call buttons for easy customer engagement

## Getting Started

### Local Development

1. Clone the repository:
   ```bash
   git clone https://github.com/davidolagundoye2-ctrl/bookish-guacamole.git
   ```

2. Open `index.html` in your web browser or use a local server:
   ```bash
   # Using Python 3
   python -m http.server 8000
   ```

3. Visit `http://localhost:8000` in your browser

## Publishing with GitHub Pages

1. Go to your repository settings
2. Navigate to **Pages** section
3. Select `main` branch as source
4. Click **Save**
5. Your site will be published at: `https://davidolagundoye2-ctrl.github.io/bookish-guacamole/`

## Customization

### Update Restaurant Information

Edit `index.html` to update:
- Restaurant name and location
- Phone number
- Menu items
- Contact information

### Styling

Modify `css/styles.css` to:
- Change colors (currently using `#c59d5f` for accent color)
- Update fonts
- Adjust spacing and layout
